# Lane Lab releases

Builds of Lane Lab, a bowling shot tracker for Bluetooth ball sensors.

Download the latest version from [Releases](https://github.com/aceman03/lane-lab-releases/releases/latest):

- **Windows:** `Lane-Lab.exe` (portable, nothing to install)
- **Android:** `Lane-Lab.apk` (open it on your phone to install or update)

Lane Lab checks this repo for updates when it opens.
